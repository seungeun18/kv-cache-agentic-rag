# SUMMARY

KIVI와 InfiniGen은 데이터 센터 및 클라우드 기반의 장문맥 LLM 서빙을 위한 KV 캐시 최적화 기술로, 각각 소프트웨어 및 하드웨어/시스템 접근 방식을 대표합니다. KIVI는 GPU에서의 메모리 효율성을 높이고, 도입 복잡성을 줄이며, 장문맥 처리에 강점을 보이는 반면, InfiniGen은 CPU 메모리를 활용하여 GPU 메모리의 오버헤드를 줄이고, 처리량과 지연 시간을 최적화하는 데 중점을 둡니다. 두 기술 모두 장문맥 확장성에 긍정적인 영향을 미치지만, KIVI는 도입 절차와 운영 비용에 대한 정보가 부족한 반면, InfiniGen은 CPU 메모리 관리의 중요성을 강조합니다.

# 1. 분석 배경

KV 캐시는 대형 언어 모델(LLM)에서 중요한 역할을 하며, 메모리 사용의 효율성을 높이고 처리 성능을 개선하는 데 기여합니다. 그러나 KV 캐시의 비효율성은 LLM의 성능 저하를 초래할 수 있으며, 이는 데이터 센터 및 클라우드 기반 서비스의 운영 비용과 성능에 직접적인 영향을 미칩니다. 따라서 KV 캐시 최적화 기술의 비교는 이러한 문제를 해결하기 위한 중요한 요소로 작용합니다.

# 2. 대상 기술 및 선정 방식

- Selection method: Human-based
- SW technology: KIVI
- HW/system technology: InfiniGen

KIVI는 소프트웨어 기반의 접근 방식을 통해 GPU 메모리의 효율성을 극대화하는 데 중점을 두고 있으며, InfiniGen은 하드웨어 및 시스템 최적화를 통해 CPU 메모리를 활용하여 GPU 메모리의 부담을 줄이는 방식으로 서로 다른 접근 방식을 대표합니다.

# 3. 기술 개요

## 3.1 KIVI
KIVI는 2비트 비대칭 양자화를 사용하여 KV 캐시의 메모리 효율성을 높이며, GPU HBM 메모리 사용을 최적화합니다. 이 기술은 장문맥 처리에 적합하며, 다중 사용자 및 배치 처리에 강점을 보입니다.

## 3.2 InfiniGen
InfiniGen은 KV 캐시를 CPU 메모리로 오프로드하여 GPU 메모리의 저장 오버헤드를 줄이고, 필요한 데이터만을 전송하여 처리량을 향상시킵니다. 이 기술은 장문맥 처리에서 우수한 성능을 보이며, CPU 메모리 관리의 중요성을 강조합니다.

# 4. 시장성 관점 평가

## 4.1 KIVI
KIVI는 기존 GPU 인프라와의 호환성이 높고, 도입 복잡성이 낮으며, 운영 비용 절감 가능성이 있지만, 도입 절차와 운영 비용에 대한 구체적인 정보가 부족합니다.

## 4.2 InfiniGen
InfiniGen은 기존 시스템과의 호환성이 좋고, 도입 복잡성이 낮으며, 비용 효율성을 높일 수 있는 잠재력을 가지고 있습니다. 그러나 CPU 메모리 관리의 필요성으로 인해 운영 비용에 대한 명확한 영향은 불확실합니다.

## 4.3 시장성 관점 비교
KIVI는 도입 복잡성과 비용 절감 가능성에서 긍정적인 요소를 보이지만, 구체적인 정보가 부족합니다. InfiniGen은 기존 시스템과의 통합이 용이하나, CPU 메모리 관리의 필요성이 존재합니다.

# 5. 도메인 적용 관점 평가

## 5.1 KIVI
KIVI는 메모리 효율성, 장문맥 확장성, 다중 사용자 처리에 강점을 보이며, 클라우드 기반 LLM 서비스에서의 적용 가능성이 높습니다. 그러나 Throughput, Latency, 데이터 이동에 대한 정보가 부족합니다.

## 5.2 InfiniGen
InfiniGen은 HBM 메모리 효율성, 처리량, 지연 시간, 장문맥 확장성 등 여러 측면에서 긍정적인 평가를 받으며, 클라우드 기반 LLM 서빙에 적합합니다. 그러나 CPU 메모리 관리의 중요성을 고려해야 합니다.

## 5.3 도메인 관점 비교
KIVI는 메모리 효율성과 다중 사용자 처리에 강점을 보이는 반면, InfiniGen은 처리량과 지연 시간 최적화에 중점을 두고 있습니다. 두 기술 모두 장문맥 처리에 긍정적인 영향을 미치지만, 각각의 접근 방식에서 차이가 있습니다.

# 6. 관점 간 비교 및 시사점

KIVI는 GPU 메모리의 효율성을 높이는 데 중점을 두고 있으며, InfiniGen은 CPU 메모리를 활용하여 GPU 메모리의 부담을 줄이는 방식으로 서로 다른 장단점을 가지고 있습니다. KIVI는 도입 복잡성과 운영 비용 절감 가능성에서 긍정적인 요소를 보이지만, 구체적인 정보가 부족하여 평가에 한계가 있습니다. InfiniGen은 기존 시스템과의 통합이 용이하나, CPU 메모리 관리의 필요성으로 인해 운영 비용에 대한 불확실성이 존재합니다.

# 7. 한계점

이 분석은 주로 공개된 연구 논문을 기반으로 하였으며, 실제 상용화에 대한 증거가 제한적입니다. 시장 결론은 추론을 포함할 수 있으며, 출판과 상용화 간의 시간 지연이 존재합니다. 또한, RAG 검색의 한계로 인해 정보의 정확성과 완전성이 보장되지 않을 수 있습니다.
